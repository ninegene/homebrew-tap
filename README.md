# homebrew-tap

Homebrew formulae for [ninegene](https://github.com/ninegene) projects.

```sh
brew install ninegene/tap/shell-explain
```

| Formula | Installs | Source |
| --- | --- | --- |
| `shell-explain` | the `explain` command | [ninegene/shell-explain](https://github.com/ninegene/shell-explain) |

Formulae build from source, so they need no pre-built binaries. To update after a new release, change `url` and `sha256` in the formula (`curl -sL <url> | shasum -a 256`).
